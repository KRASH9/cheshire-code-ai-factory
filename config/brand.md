# Cheshire Code — Brand Guide

## Account
- TikTok: @cheshire193
- Display name: CHESHIRE CODE
- Bio: Cheshire Cat's wisdom

## Creative direction
- Genre: fantasy, magical realism, mystery, symbolic micro-stories.
- Visual motifs: enchanted books, ancient forests, glowing trees, portals, doors, clocks, stars, purple-blue magical light.
- Mood: wondrous, mysterious, emotionally resonant; occasionally eerie, never generic horror.
- Composition: one clear focal point, cinematic depth, readable negative space.
- Text: short English phrases, carefully proofread and legible on mobile.

## Story principles
- Each video should communicate one idea or emotional turn.
- Open with a curiosity gap in the first seconds.
- Prefer visual storytelling over long explanations.
- Use original wording; do not imitate a living creator's distinctive style.
- End with a memorable image, question, or subtle reveal.

## Quality checklist
- [ ] Hook is clear immediately.
- [ ] Visuals match the story.
- [ ] On-screen text is spelled correctly and readable.
- [ ] No unintended logos, watermarks, or distorted lettering.
- [ ] Sound and assets are licensed or otherwise authorized.
- [ ] Final video reviewed before publishing.
