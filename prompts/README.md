# Prompt Library — CHESHIRE CODE

This library is governed by config/brand.md, the locked source of truth. The goal is to create new original wisdom videos with the same speaking Cheshire Cat. Existing story continuity is preserved, but it does not restrict new concepts.

## Canonical prompts
- IDEA_RESEARCH.md — find fresh themes and research online inspiration.
- WISDOM_IDEA_GENERATOR.md — turn a theme into original ideas, hooks and short wisdom lines.
- MASTER_VIDEO_PROMPT.md — exact 10-second Meta AI prompt with a speaking Cheshire Cat.
- COVER_PROMPT.md — cover and typography.
- POST_PACKAGE.md — English post, short description, hashtags and first comment.
- COMMENT_REPLIES.md — comment response voice.
- SERIES_BIBLE.md — continuity for the seven existing series.

## New-video workflow
1. Research a current conversation or choose an evergreen human theme.
2. Record the source / insight; do not copy another creator's words.
3. Create 3–5 original concepts and select the strongest.
4. Write one concise English wisdom line that Cheshire himself can speak naturally in one second.
5. Build the exact 10-second story: hook action → one simple cat action → magical turn → spoken line → one second silence.
6. Prepare the Meta AI master prompt, cover prompt and complete post package.
7. Create the video manually in Meta AI; check face consistency, turquoise markings, English lip sync, British voice, physics and timing.
8. Review manually; publish manually at 20:30 Warsaw / 19:30 London only after at least 24 hours and when the previous video is no longer actively growing.

No paid APIs, automated rendering or automatic TikTok publishing. No changes to the locked cat, voice, world, duration or schedule without explicit owner approval.
