# Prompt Library — CHESHIRE CODE

This library is governed by [config/brand.md](../config/brand.md), the locked source of truth. No generic fantasy, default forests, cute/cartoon cats, extra speakers or alternate character designs.

## Canonical prompts
- [MASTER_VIDEO_PROMPT.md](MASTER_VIDEO_PROMPT.md) — Meta AI prompt and exact 10-second structure.
- [COVER_PROMPT.md](COVER_PROMPT.md) — cover and typography.
- [POST_PACKAGE.md](POST_PACKAGE.md) — English post, short description, hashtags and first comment.
- [COMMENT_REPLIES.md](COMMENT_REPLIES.md) — comment response voice.
- [SERIES_BIBLE.md](SERIES_BIBLE.md) — continuity for the seven existing series.

## Workflow
Choose an owner-approved idea or existing series; prepare video prompt, cover prompt and post package; create the video manually in Meta AI; review manually; publish manually at 20:30 Warsaw / 19:30 London only after at least 24 hours and when the previous video is no longer actively growing.

No paid APIs, automated rendering or automatic TikTok publishing.
